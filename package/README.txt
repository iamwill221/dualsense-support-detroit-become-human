DualSense support for Detroit: Become Human (PC)
================================================

Play with a PS5 DualSense controller: PlayStation buttons on screen, rumble,
lightbar and motion. Nothing else in the game is changed.

INSTALL
  1. Double-click Install.bat.
     It finds the game by itself. If Windows asks for permission, click Yes.
  2. In Steam: right-click Detroit: Become Human > Properties > Controller
     > choose "Disable Steam Input".
  3. Connect your DualSense (USB cable or Bluetooth) and start the game.

If a game update ever removes DualSense support, double-click Install.bat again.

UNINSTALL
  Double-click Uninstall.bat. (Steam > Verify integrity of game files also works.)

PROBLEMS?
  - Xbox buttons on screen: Steam Input is still on (step 2).
  - Controller not working: connect it before starting the game, or try a USB cable.
  - "Windows protected your PC": click More info > Run anyway.
  - A log is written to %TEMP%\dualsense_proxy.log (paste that path in Explorer).
